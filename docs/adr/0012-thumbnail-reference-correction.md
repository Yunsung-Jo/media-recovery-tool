# 0012. EXIF 썸네일을 참조 오라클로 잔여 밀림·색 캐스트를 보정한다

- **날짜:** 2026-07-23
- **상태:** Accepted

## 배경

ADR 0011의 공간 보정 이후에도 두 잔여 문제가 남는다. `phase_cuts` 근거가 없는 파일의 숨은 순환
밀림(엔트로피 연산 0이어도 존재)과, DC 재설정 재개가 남기는 세그먼트 상수 색 캐스트다. 정답 원본이
없어 두 문제 모두 수락 판정의 근거 신호가 부족했다.

카빙 원본의 EXIF 썸네일은 손상되지 않은 저해상 정답 근사이며, 이 코퍼스에서 손상이 심한 파일일수록
보유율이 높다(severe 63.8%, clean 12.6%). 다만 실측에서 두 함정이 확인됐다. 썸네일은 파일별로 메인과
프레이밍(스케일·세로 오프셋)이 다를 수 있고, 카메라의 썸네일 톤·채도 처리도 메인과 다르다. 이를
무시하면 정상 파일에서 정수 MCU 근처의 가짜 밀림 밴드와 색 과보정이 생기며, 행 상관 절대값으로는
진짜 밀림과 구분할 수 없었다(정상 파일에서도 중앙값 0.97).

## 결정

썸네일을 생성 입력이 아니라 **참조 오라클**로만 사용한다. 출력 픽셀은 항상 복구본에서 오고, 썸네일은
추정과 수락 판정에만 쓴다. 후처리 도구 `thumbref.py`(`carver/thumbref.py`)로 구현한다.

1. **전역 정합 선행:** scale 0.80~1.25와 세로 dy를 함께 탐색한다. 스코어는 행별 자유-시프트 최대
   순환 상관의 중앙값이라 순환 밀림이 있는 손상 파일에서도 성립한다. 스코어 0.30 미만이면 오라클을
   포기한다(회색 지배·평탄 콘텐츠·깨진 썸네일).
2. **행별 밀림 추정:** 정합 좌표계에서 FFT 순환 상관으로 행별 시프트를 얻고 원본 SOF의 MCU
   격자(16px)로 스냅한다. 수락 게이트는 0-시프트 대비 마진(≥0.10), 블록 NCC 재검증(roll≥0.25,
   개선≥0.08), 최소 밴드 높이다. 프레이밍 dx는 근사-0 행 중앙값으로 분리한다.
3. **색 밴드 보정:** 채널별 강건 gain+offset 톤 모델(썸네일 렌더 차이 흡수)의 잔차만 YCbCr 밴드로
   취급한다. 게이트는 채널별 `[Y 6.0, Cb 3.5, Cr 3.5]` — 비네팅·노출 렌더 차이는 Y에 몰리고 손상
   캐스트는 크로마가 지배한다. 적용 후 잔차를 1회 재적용해 수렴시킨다.
4. **self-check 롤백:** 시프트를 적용한 캔버스 행들에서 0-시프트 상관 중앙값이 0.01 이상 좋아지지
   않으면 전량 되돌린다. 전체 행 중앙값은 국소 밴드 보정에 둔감해 판정 기준으로 쓰지 않는다.
4a. **밀림 반복 보정:** 1회 `apply_shift`는 저해상 썸네일·다밴드 광범위 재동기에서 큰 밴드를 놓친다.
   재추정→적용을 수렴(남은 밀림 0)까지 반복하되, 각 회차를 위 self-check로 검증해 개선될 때만
   채택한다(개선 없으면 그 회차를 버리고 정지). 순환 roll 부작용·발산을 회차별 게이트가 막고,
   정상 가드는 첫 회차 시프트가 0이라 반복을 시작하지 않는다.
5. **적용과 저장:** 시프트는 MCU 행 단위 순환 roll(16px 배수), 색은 YCbCr 가산으로 픽셀 도메인에서
   적용한다. MCU 격자·서브샘플링은 카빙 원본 SOF를 따르고 복구본의 양자화 테이블을 재사용해 추가
   손실을 최소화한다. 보정이 없으면 바이트를 그대로 복사한다.

## 대안

| 대안 | 기각 이유 |
|---|---|
| 썸네일→고해상 생성 모델(초해상·인페인팅) | 학습할 정답 쌍이 없고, 복구본에 남아 있는 실제 디테일을 버리고 환각으로 대체한다. 개인 사진에 없던 내용을 만들지 않는 원칙에 위배된다. |
| `grid_sample` 경사하강 단독 최적화 | bilinear 워핑의 그래디언트는 ±1px 국소 정보라 수백~천 px 순환 밀림에 수렴하지 않고, tanh 상한은 큰 변위에서 포화된다. 행-상수 순환 모델은 FFT로 O(W log W) 전역 탐색이 가능하다. |
| 행 상관 절대값(conf)을 수락 게이트로 사용 | 정상 파일에서도 콘텐츠 자기 유사가 conf 0.9+의 가짜 정수 MCU 밴드를 만들어 판별력이 없었다. |
| 전체 행 중앙값 dmatch로 수락 판정 | 국소 밴드 보정은 전체 중앙값을 거의 움직이지 않아 정당한 보정을 롤백으로 오판했다. 적용 행 한정 판정으로 교정했다. |
| 수평 그래디언트 맵의 2D 상관 정합 | 손상 밴드가 그래디언트 맵을 오염시켜 고손상 표본에서 전부 정합 실패했다. 행별 자유-시프트 스코어가 이를 대체한다. |
| `recover_file` 내부 통합 | 현 시점의 공간 보정 변경이 전수 회귀 전이라 검증 부채가 겹친다. 독립 후처리로 먼저 편입하고, 전수 회귀 후 엔진 통합(세그먼트 지도·행 중간 경계)을 재검토한다. |

## 결과

썸네일이 있는 복구본에 한해 잔여 밀림과 색 캐스트를 근거 있는 게이트로 보정할 수 있다. 정상 가드와
무변경 파일은 identity로 남고, 근거가 부족한 파일은 정합 단계에서 보수적으로 스킵된다. 광범위 재동기
파일은 행 통째 roll의 표현력 한계로 개선이 제한되며, 세그먼트가 행 중간에서 갈리는 색 밴드의 x방향
변화도 행 상수 모델로는 남는다 — 둘 다 resync 엔진의 세그먼트 지도와 결합하는 후속 과제다.
수치 기준선과 검증 요약은 [evaluation.md](../evaluation.md)를 따른다(상세 실험 기록은 로컬
`shift_experiments/`, Git 비추적).
