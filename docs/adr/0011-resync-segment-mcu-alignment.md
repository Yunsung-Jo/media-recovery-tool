# 0011. 복구 절단 구간을 MCU 행 위상으로 재배치한다

- **날짜:** 2026-07-21
- **갱신:** 2026-07-23
- **상태:** Accepted

## 배경

바이트 편집과 비트 재동기는 손상 뒤의 유효 엔트로피를 다시 디코드하지만, 각 실패에서 실제로 사라진 MCU
수는 알 수 없다. 재개 데이터를 실패 MCU 위치에 그대로 채우면 이후 조각이 행 안에서 순환 이동하거나
왼쪽·오른쪽이 뒤바뀐 채 이어지는 수평 밀림이 남는다. 압축 비트 수는 MCU마다 달라 재개 비트 간격만으로
유실 MCU 수를 안정적으로 환산할 수 없었다.

최상단은 대체로 원래 위상의 좋은 기준이지만 항상 그렇지는 않다. 또한 한 열에서 반복되는 강한 자연 경계는
실제 행 끝과 비슷해 단일 조각의 최고 경계만으로는 양쪽을 구분할 수 없다. 따라서 첫 조각을 절대 고정하거나
각 조각의 가장 강한 경계를 무조건 행 끝으로 간주하는 방식 모두 회귀를 만들었다.

## 결정

유효 MCU 전량 보존보다 밀림 제거를 우선한다. 엔트로피 복구와 헤더 후보 선택을 끝낸 뒤 선택된 렌더에만
다음 공간 후처리를 적용한다.

1. 수락한 모든 바이트 편집과 재동기의 실패 MCU를 절단점으로 기록해 복구 밴드를 만든다. 각 밴드의
   좌우 MCU 경계에서 DC 변화에 둔감한 반복 행 위상을 추정하고, 중간·긴 밴드는 전체 폭 경계 profile의
   순환 상관을 함께 사용한다. 정밀 절단점 배치가 안전하지 않으면 실제 재동기 경계만 사용한 coarse
   배치로 한 번 후퇴한다.
2. 1차 배치 뒤 원본 샘플링에서 계산한 MCU 행 높이마다 경계를 검사한다. 1·2·3·4픽셀 strip이 모두
   비슷한 비영 위상을 가리키는 strict 사건만 첫 전역 해의 씨앗으로 사용한다. 최상단 행의 절대 위상은
   0으로 고정하고 각 경계의 상대 위상을 아래 행들에 누적한다.
3. 첫 전역 배치로 드러난 짧은 연쇄는 네 strip 중 셋이 지지하는 relaxed 합의로 최대 5회 더 탐색한다.
   각 후보는 직전 결과를 다시 옮기지 않고 같은 1차 RGB와 source-owner map에서 누적 절대 위상을 한 번만
   렌더한다. 따라서 반복 패스가 픽셀을 재인코딩하거나 소유권 손실을 숨기지 않는다.
4. 중간 탐색 상태는 잔차 합을 직전 상태의 85% 이하로 줄이고, 전체 MCU의 5% 손실 한도와 source-owner의
   유일·단조 조건을 지켜야 한다. 중간 상태가 독립 exact·soft·multistrip 감사에서 일시적으로 안전하지
   않아도 다음 연쇄를 노출할 수 있지만, 최종 반환 후보는 시작 상태와 이전 안전 후보를 회귀시키지 않아야
   한다. 안전 후보는 exact, multistrip, soft, relaxed 잔차를 차례로 우선하고 그 다음 손실량으로 고른다.
5. 전역 후보가 없거나 끝까지 안전한 상태가 없으면 절단점 주변의 구조적 짧은 구간 보정과 기존 보수적
   행 스티치를 실행한다. 전역 후보가 채택되면 같은 경계를 다시 맞추지 않도록 두 국소 단계를 생략한다.
6. 최상단 복구 밴드는 MCU 0의 `resync` 절단 기록과 MCU 0의 비영 시작 비트 세그먼트가 모두 있을 때만
   이동할 수 있다. 전역 행 보정은 그 경우에도 현재 1차 배치의 첫 행을 절대 위상 0으로 둔다. 반대로
   `phase_cuts=[]`는 수락된 편집·재동기 근거가 없다는 뜻이므로 픽셀 신호만으로 공간 이동을 만들지 않는다.
7. 출력 크기는 유지한다. 양의 간격은 RGB 128 MCU로 남기고 겹침에서는 뒤 밴드가 앞 밴드를 대체한다.
   원본 MCU 순서를 역전하거나 복제하지 않는다. 부분 가장자리 MCU는 잘린 렌더가 아니라 전체 디코드
   계수 픽셀로 이동한 뒤 헤더 크기로 자른다.

헤더 후보의 구조 게이트와 자체 헤더 우월 비교는 보정 전 렌더로 수행한다. 픽셀 위상 신호는 엔트로피
재동기나 헤더 후보 수락에 사용하지 않는다.

## 대안

| 대안 | 기각 이유 |
|---|---|
| 재개 bit 간격을 평균 bits/MCU로 환산 | 손상 구간에서 잘못 디코드된 비트 소비와 MCU별 가변 비트율 때문에 고정 실패 표본의 실제 위상과 크게 달랐다. 동률 해소의 약한 힌트로만 남겼다. |
| 모든 MCU를 보존 | 겹침을 허용하지 않으면 누적 밀림을 제거할 수 없다. 이번 목표는 제한된 소실보다 정렬을 우선한다. |
| 절단면이 반드시 개선될 때만 이동 | 실제 유효 보정도 손상 경계 자체는 악화될 수 있어 긴 후속 밴드의 정렬을 놓쳤다. |
| 가장 강한 반복 경계를 무조건 행 경계로 채택 | 정렬된 자연 세로 경계를 행 경계로 오인하는 합성·정상 회귀가 발생했다. 전체 폭 signature 연쇄가 이 모호성을 줄인다. |
| 최상단 복구 밴드를 항상 오프셋 0으로 고정 | 일반 파일에는 강한 prior지만 MCU 0에서 실제 재동기된 표본을 영구히 잘못 고정한다. MCU 0 resync 절단과 비영 시작 비트가 함께 있을 때만 예외를 연다. |
| 절단 밴드나 한 경계씩 순차 보정 | 한 재동기 세그먼트 안에서도 여러 행 위상이 나타났고, 앞 보정의 픽셀·소유권 손실이 다음 판단에 누적됐다. 상단 고정 절대 상태를 원래 1차 렌더에서 매번 다시 만든다. |
| 캔버스 크기를 늘려 모든 MCU 유지 | 원래 해상도와 좌표 계약을 바꾸고 물리적으로 없던 행을 생성한다. |

## 결과

`RECOVERED`와 `HEADER_RECOVERED`는 제한된 MCU 삽입·유실을 대가로 편집·재동기 뒤의 행 밀림을 바로잡을
수 있다. 엔트로피 연산이 0이어도 공간 보정이 채택되면 원본 보존 분기로 덮어쓰지 않고 `RECOVERED`로
재인코딩한다. `report.csv`는 공간 변화 여부, 절단 밴드, 전역 패스·위상 변화, 국소 절단점, 삽입·유실과
최종 안전 기각을 구분해 기록한다. 완전히 모호한 경계와 안전 게이트를 넘는 후보에는 밀림이 남을 수 있다.
DC=0 재개의 색 캐스트는 이 결정의 범위가 아니다.
